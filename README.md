# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/gnani.git
```

```
cd gnani
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Backend

```bash
cd backend
npm install
npm run dev
```
